# Orbit Desktop App

The frontend for the Orbit AI Companion. Built on Electron, React, Vite, and TailwindCSS.

## Sci-Fi Aesthetic
This desktop client is designed to look like a cinematic hacking or sci-fi HUD. It supports:
- Video backgrounds
- Edge-TTS voice playback
- Interactive UI sound effects
- Frameless window dragging

## Commands
- `npm install` - Install dependencies
- `npm run dev` - Start the Electron development server
- `npm run build` - Build the production app

## OTA Updates
Orbit is configured with `electron-updater` to pull OTA updates seamlessly from GitHub Releases.
